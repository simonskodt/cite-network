How to use the Citation Network

Navigating
ScrollZoom in / out
Drag backgroundPan the graph
Click nodeSelect — see title, DOI, authors, and actions in the panel below
Right-click nodeContext menu: expand citations or remove the node
Adding papers
LoadLoad N seed papers into the graph; set the count with the number input
Search barFind by title, author, year, or institution — results appear in the sidebar; click to add
+ NewCreate a new paper manually, or paste text for AI extraction
BulkImport multiple papers by DOI via CrossRef, or free-text via AI
Drawing citation arrows
Hold ~400 msEnter drag mode — drag the dashed arrow to a target node
Double-click nodeEnter persistent draw mode — then click any other node to connect
EscCancel drawing at any time
Exploring connections
Cited by thisExpand outward — load papers this node cites
Citing thisExpand inward — load papers that cite this node
All / Seed / AddedFilter tabs — show papers in the graph filtered by source
